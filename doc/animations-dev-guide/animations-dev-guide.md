# Animation Development Guide

## Setup

### Clone repo

Clone sample-animation.

### Rename

Rename sample-animation to new name.

### Register on development

Register animation on development page.

## Testing

Times for testing:

- Delay:0s, Duration: 2s
- Delay: 2s, Duration: 5s

## Test cases

### One slide cases

#### Case 1 (happy path)
- press play and wait for 2-3 loops
#### Case 2 (manual position - 3 variations)
- press play and pause before/during/after animation start and drag timeline handle left and right
#### Case 3 (change resolution)
- press play and user resolution slider to change resolution 
### Case 4  (2 slides)
- create second slide with small duration
- press play and wait for 2-3 loops
### Case 5 (test on bucket - after uploading extension)
- publish project to bucket
- resize window to check responsive behavior on all devices

## Upload animation bundle

Upload animation extension and make another round of testing
