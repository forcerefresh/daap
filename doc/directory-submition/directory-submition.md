## Title

Web Slider

## Short description

Web Slider is an animation platform for the web that gives you a wide range of possibilities to create and publish visually rich content.

## Middle description

Web Slider is an animation platform for the web that gives you a wide range of possibilities to create and publish visually rich content. It allows integration with any website through HTML and JS. Responsive configuration has a rich set of options that allow you to fine-tune the visual experience on different devices.

## Long Description

Web Slider is an animation platform for the web that gives you a wide range of possibilities to create and publish visually rich content. It allows integration with any website through HTML and JS. Responsive configuration has a rich set of options that allow you to fine-tune the visual experience on different devices. The built-in preview allows you to create an animation that looks perfect on all devices and all resolutions. Select device and set the correct resolution to get a real-time change in preview mode.
